# Address Book

## 📌 Project Overview

The Address Book is a C programming project that allows users to manage contact information efficiently.

The application provides basic operations such as adding, searching, editing, deleting, and displaying contacts. Contact information can also be stored in a file so that the data can be retained between program executions.

## 🚀 Features

- Add a new contact
- Search for a contact
- Edit existing contact details
- Delete a contact
- Display all contacts
- Save contacts to a file
- Load contacts from a file
- Exit the application

## 🛠️ Technologies Used

- C Programming
- File Handling
- Structures
- Arrays
- Functions
- Pointers
- String Handling
- Modular Programming

## 📂 Project Structure

| File | Description |
|------|-------------|
| `main.c` | Contains the main menu and program execution |
| `contact.c` | Implements contact-related operations |
| `contact.h` | Function declarations for contact operations |
| `file.c` | Handles file operations |
| `file.h` | Function declarations for file handling |
| `types.h` | Contains structures and type definitions |
